<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI environment → PyPI | uv fetches packages from PyPI during `uv sync --frozen` — locked tree mitigates substitution attacks |
| Developer machine → repo | git commit includes uv.lock; without it, `uv sync --frozen` in CI fails deterministically |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | pyproject.toml — godoo-client pin | mitigate | Pin `godoo-client>=0.2,<0.3` with explicit upper bound; upper bound prevents silent major/minor upgrade to a hypothetical malicious or breaking future version |
| T-01-02 | Tampering | uv.lock — dependency tree integrity | mitigate | Commit uv.lock and use `uv sync --frozen` in CI; any lockfile mutation causes CI failure on next run |
| T-01-03 | Tampering | npm/pip/cargo installs — slopcheck | accept | All packages in Package Legitimacy Audit table are either internal (godoo-client, Marc is author) or well-established ecosystem tools (ruff, mypy, pytest, fastmcp) with HIGH disposition; no [SUS] or [SLOP] packages present |
| T-01-04 | Information Disclosure | CI secrets | accept | Phase 1 CI has no secrets — lint + type-check + empty pytest require no credentials or API keys |
| T-01-05 | Spoofing | godoo meta-package trap | mitigate | Dependency is `godoo-client` not `godoo`; the meta-package has no importable code and its presence would surface immediately as an import error |
| T-01-06 | Denial of Service | CI Python version unavailability | mitigate | Use `astral-sh/setup-uv@v5` which installs Python via uv's own toolchain rather than relying on setup-python tool-cache; Python 3.14.5 confirmed available |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | All packages [VERIFIED: PyPI registry]; no blocking checkpoint needed since all packages are pre-approved (see Package Legitimacy Audit in RESEARCH.md) |

- Repudiation — no audit surface
- Information Disclosure (runtime) — no network handlers, no credentials processing
- V2-V6 ASVS categories — none implemented yet
</threat_model>
