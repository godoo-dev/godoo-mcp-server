    _catalog_lock: asyncio.Lock | None = None
    def _get_lock() -> asyncio.Lock:
        global _catalog_lock
        if _catalog_lock is None:

  WRONG: _catalog_lock: asyncio.Lock = asyncio.Lock()  # ← NEVER at module level

  TTLCache: _catalog_cache: TTLCache[CacheKey, dict[str, Any]] = TTLCache(maxsize=32, ttl=3600)
  CacheKey = tuple[str, str, str]  # (url, database, schema_hash)

  compute_schema_hash(client: OdooClient) -> str | None:
    3 parallel search_read probes via asyncio.gather:
      "ir.model" fields=["write_date"] order="write_date desc" limit=1
      "ir.model.fields" fields=["write_date"] order="write_date desc" limit=1
      "ir.module.module" [["state","=","installed"]] fields=["write_date"] order="write_date desc" limit=1
    Return f"{model_date}|{field_date}|{module_date}". Return None on any Exception.

  get_catalog_snapshot(client, url, database) -> dict[str, Any]:
    hash = await compute_schema_hash(client)
    if hash is None: return {"schema_hash": None, "models": [], "cached": False}
    key = (url, database, hash)
    async with _get_lock():
        if key in _catalog_cache: return {**_catalog_cache[key], "cached": True}
        snapshot = await _build_snapshot(client, hash)
        _catalog_cache[key] = snapshot
        return {**snapshot, "cached": False}

  get_model_entry_from_cache(model_name: str) -> dict[str, Any] | None:
    Iterates _catalog_cache.values(); looks for entries where entry["model"] == model_name
    Returns None if cache cold or model not found. No await, no OdooClient.

  _build_snapshot(client, schema_hash): Builds the actual snapshot dict from Odoo.
    Lazy: introspect core models (mail.message, res.users, res.partner, ir.attachment, ir.ui.menu) via search_read on ir.model filtered to these names.
    Return {"schema_hash": hash, "models": model_list, "cached": False}.

| catalog.py → Odoo (schema probe) | 3 write_date RPC calls; result used as cache key discriminator only |
| resources.py → catalog cache | Read-only access; no Odoo calls from resource handlers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Information Disclosure | Catalog cache key | mitigate | Key = (url, database, schema_hash) — credentials (username, password) are never part of the key; D-10/D-12; verified by test_cache_key_excludes_credentials |
| T-04-03-02 | Tampering | Schema-hash collision | accept | Hash is write_date|write_date|write_date; collision requires Odoo DB write access (attacker already has write access if they can change write_date); not a client-side concern |
| T-04-03-03 | Tampering | Cache poisoning via concurrent writes | mitigate | asyncio.Lock (_get_lock()) guards all cache reads and writes; lazy init avoids Python 3.14 event-loop-before-lock issue |
| T-04-03-04 | Information Disclosure | Cross-user cache data | mitigate | Schema data (ir.model, ir.model.fields) is per-target not per-user; no user-specific data stored in catalog snapshots; get_model_entry_from_cache reads schema only |
| T-04-03-05 | Denial of Service | compute_schema_hash failure | accept | Returns None on any exception; caller falls back to {"schema_hash": None, "models": []}; agent can still use all tools; no server crash |
</threat_model>
