## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → mail tool | Untrusted: model, res_id, body, activity params come from agent-provided input |
| Tool handler → Odoo | Tool calls Odoo as the requesting user; Odoo enforces ACL per D-12 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01-01 | Spoofing | mail tool handlers: credential resolution | mitigate | Per-request OdooClient built from request.state.odoo_creds only; no module-level client; no cross-user bleed (AUTH-04 pattern) |
| T-04-01-02 | Information Disclosure | ToolError message content | mitigate | raise ToolError(str(e)) — str(e) only, never repr(e) or traceback.format_exc(); D-08 pattern enforced |
| T-04-01-03 | Elevation of Privilege | mail_post_message / mail_log_note | accept | Odoo enforces message_post ACL per the requesting user's credentials; this server does not grant additional rights |
| T-04-01-04 | Tampering | mail_schedule_activity inputs (date_deadline, activity_type_id) | mitigate | pydantic type validation via fastmcp (str, int types enforced); OdooError surfaces invalid values as ToolError |
| T-04-01-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages introduced in this plan; cachetools added in Plan 02 pyproject.toml change; Package Legitimacy Audit in RESEARCH.md confirms all packages approved |
