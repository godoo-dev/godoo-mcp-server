## Phase Goal

**As a** developer deploying godoo-mcp-server, **I want to** POST to the stateless Streamable HTTP endpoint with per-request Odoo credentials and receive a valid MCP response, **so that** I can confirm the full credential-resolution-to-Odoo-client chain works with no cross-user bleed.

<objective>
Wire the stateless Streamable HTTP MCP endpoint with per-request credential resolution.

Purpose: Deliver the core vertical slice — HTTP request with X-Odoo-* headers flows through a pure ASGI credential middleware, resolves credentials into OdooCredentials, injects them into scope["state"], and a registered MCP tool can read them to build a fresh per-request OdooClient. No shared state, no Mcp-Session-Id, HTTP 401 with field enumeration when credentials are absent.

Output:
- credentials.py — OdooCredentials dataclass + CredentialMiddleware (pure ASGI)
- server.py — FastMCP mcp instance + create_app() ASGI factory

- __main__.py — server start wired in else branch
</objective>

## Trust Boundaries

| Boundary | Description |
